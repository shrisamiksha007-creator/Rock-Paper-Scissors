# Rock Paper Scissors 🪨📄✂️

A full-stack Rock Paper Scissors game built with Java Spring Boot backend and HTML/CSS/JS frontend.

## 🔗 Live Demo
[Play the game here](https://shriji-rock-paper-scissors.netlify.app)

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Railway (backend), Netlify (frontend)

## 🎮 How to Play
1. Choose Rock, Paper, or Scissors
2. Click Play
3. See if you beat the computer!

## 🚀 Run Locally
1. Clone the repository
2. Run `mvn spring-boot:run` in the `demo` folder
3. Open `index.html` in browser
